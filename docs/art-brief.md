# WithYou — 아트/애니메이션 외주 브리프 (Art & Animation Brief)

> 외주 작업자에게 그대로 전달할 수 있는 문서입니다. (국제 작업자용 영어 번역본 필요 시 요청)

## 0. 한 줄 소개
**WithYou (가제 CoupleWidget)** — 커플용 데스크톱 위젯입니다. 각자 PC 화면 우하단에 작은 캐릭터가 앉아 있고, **내 화면의 캐릭터 = 상대방**을 나타냅니다. 캐릭터는 상대방의 실시간 PC 활동(게임/공부/음악/영상/자리비움)에 반응합니다. Steam 출시 예정.

작업물은 **Rive 파일(`.riv`)** 로 납품해야 하며, 단순 그림/스프라이트가 아니라 **state machine(상태 머신) + 입력(input)** 을 갖춘 인터랙티브 리그여야 합니다.

---

## 1. 기술 제약 (반드시 지켜주세요)

| 항목 | 요구사항 |
|---|---|
| 포맷 | **Rive** (`.riv`). 런타임은 웹 `@rive-app/react-canvas` v4.x |
| 그래픽 | **벡터** 권장 (위젯 크기 0.8×~1.4× 확대축소 → 깨지면 안 됨) |
| 배경 | **완전 투명** (캐릭터만 보이고 화면에 합성됨) |
| 정렬 | 캐릭터 **발이 아트보드 바닥에 닿게** (코드가 BottomCenter, Fit.Contain으로 배치) |
| 아트보드 비율 | 세로형 권장 (현재 표시 영역 약 220×170, 벡터라 실치수는 자유 — 예: 400×400) |
| state machine | **하나의 state machine**에 아래 모든 상태/전환/입력을 담아주세요. 이름은 자유(코드가 첫 번째를 자동 재생) — 단 권장 이름 `Main` |
| 성능 | 60fps, 파일 용량 가급적 수 MB 이내 |
| 납품 | ① 편집 가능한 Rive 에디터 원본 ② 런타임용 export `.riv` 둘 다 |

> 참고: Rive 런타임은 오픈소스(MIT)라 **출시 시 런타임 라이선스 비용 없음**. (Live2D와 다른 점 — 아래 5번 참고)

## 2. 캐릭터 컨셉
- 현재 플레이스홀더로 **고양이** 캐릭터 1종(`cat-idle.riv`)이 있습니다. 이를 발전시켜도 되고, 새 방향을 제안해도 됩니다.
- 톤: **귀엽고 따뜻한 커플 감성**, 작은 화면에서도 또렷하게 읽히는 단순/명확한 실루엣.
- 표정·동작이 **멀리서도 한눈에 구분**되어야 합니다 (위젯이 작음).

## 3. 필요한 애니메이션 목록

### 3-1. 지속 상태 루프 (Activity loops) — 한 번에 하나만 재생, 반복
> 괄호는 "이 상태를 어떻게 연출하면 좋을지" 아이디어 (자유롭게 해석 가능)

| # | 상태 | 연출 아이디어 | 우선순위 |
|---|---|---|---|
| 0 | `idle` | 기본 대기 + 숨쉬기 보빙, **커서 따라보기** | **P1** |
| 1 | `gaming` | 헤드셋 + 키보드 두드리기 🎮 | **P1** |
| 2 | `working` (공부/작업) | 안경 + 책/모니터 📚 | **P1** |
| 3 | `music` | 이어폰 + 리듬 타기 🎧 | **P1** |
| 4 | `video` | 3D 안경 + 팝콘, 화면 응시 🍿 | **P1** |
| 5 | `afk` (자리비움) | 졸기/자기 💤 | **P1** |
| — | `happy` | 신난 표정 (이벤트성) | P1 |
| — | `offline` | 흐릿/시무룩 (상대 접속 끊김) — 선택, 현재는 코드가 흑백 처리 | P2 |

### 3-2. 원샷 이모트 (Emotes) — 트리거되면 1회 재생 후 현재 루프로 복귀
| 이모트 | 연출 | 우선순위 |
|---|---|---|
| `heart` | 하트 날리기 ❤️ (시그니처) | **P1** |
| `kiss` | 뽀뽀 😘 | **P1** |
| `hug` | 안기 🤗 | **P1** |
| `laugh` | 크게 웃기 😂 | **P1** |
| `sad` | 시무룩/울먹 🥺 | **P1** |
| `wave` | 손 흔들기 👋 | **P1** |
| `poke` | 콕 찌르기 반응 👉 (상대가 클릭했을 때) | **P1** |
| `celebrate` | 기념일/마일스톤 축하 🎉 (꽃가루 등) | P1 |

### 3-3. 커서 따라보기 (Look-at-cursor)
- 이미 현존 파일에 **pointer Listener** 로 구현되어 있음 — 동일 방식 유지(눈/머리가 마우스를 따라봄).
- 코드가 전역 마우스 좌표를 캔버스로 전달하므로, **pointer 위치 기반** 으로 동작하도록 만들어 주세요.

### 3-4. 립싱크 (Lip-sync) — Phase 2 (Feature 1)
- 음성/마이크 음량에 따라 입이 열리고 닫힘.
- 단순화: **입 벌림 정도를 0~100 숫자 입력으로** 받아 입 모양에 매핑 (정교한 viseme는 후순위).

### 3-5. 스킨/변형 (Skins) — Phase 3 (Feature 4)
- 같은 리그를 재사용한 **색/의상 변형 2~3종**.
- v1 권장 방식: **스킨별 별도 아트보드(또는 별도 `.riv`)**. (단일 아트보드에 skin 숫자 입력으로 전환해도 OK — 제안 환영)

### 3-6. 공유 룸 배경 (Room background) — Phase 2 (Feature 4)
- 두 캐릭터가 함께 보이는 "집/방" 배경 1종 (정적 또는 가벼운 루프).
- **캐릭터 2명이 나란히** 설 수 있는 레이아웃 고려.

## 4. ⭐ State Machine 입력 계약 (가장 중요)

코드가 아래 **입력(input) 이름/타입** 을 그대로 구동합니다. **이름·타입·값을 정확히 맞춰주세요.** (값은 앱의 내부 타입과 1:1로 매핑됩니다.)

```
State machine: (이름 자유 / 권장 "Main") — 하나만

[Number] state        // 지속 상태. 정수값:
                      //   0 = idle
                      //   1 = gaming
                      //   2 = working
                      //   3 = music
                      //   4 = video
                      //   5 = afk
[Boolean] offline     // true → 오프라인/시무룩 포즈 (선택, P2)

[Trigger] heart       // 원샷 이모트들 (트리거 후 현재 state 루프로 복귀)
[Trigger] kiss
[Trigger] hug
[Trigger] laugh
[Trigger] sad
[Trigger] wave
[Trigger] poke
[Trigger] celebrate

[Number] mouthOpen    // 0~100, 립싱크 입 벌림 (P2). 미사용 시 0
                      // 커서 따라보기는 pointer Listener로 처리(입력 불필요).
                      // 대안으로 lookX / lookY (-100~100) 노출도 가능(선택).
```

- **트랜지션**: 각 `state` 값 사이는 자연스럽게(또는 즉시) 전환. 이모트 트리거는 어느 상태에서든 재생되고 끝나면 원래 `state`로 복귀.
- 입력 이름은 **영문 그대로**(`state`, `heart` 등) 사용해 주세요 — 코드가 문자열로 참조합니다.

> 현재 상태: 코드는 아직 이 입력들을 구동하지 않고 임시로 이모지 오버레이를 띄우고 있습니다. 위 계약대로 `.riv`가 들어오면 우리가 코드에서 연결합니다.

## 5. 작업자 구인 시 주의 (발주자용 메모, 외주에 전달 X)

- 필요한 사람은 **"Rive 가능 인터랙티브 애니메이터"** — 일반 2D 애니메이터/일러스트레이터와 다릅니다.
- 한국에는 **Live2D**(VTuber 생태계) 인력이 훨씬 많고 Rive 전문가는 드뭅니다. 선택지:
  - (a) **Rive 인력**을 글로벌(Upwork, Rive 공식 Discord/커뮤니티)에서 찾기 — 권장
  - (b) **Live2D로 전환** — 국내 인력 많음. 단 **앱 렌더러 교체 필요**(Live2D Cubism Web SDK) + **Cubism 상용 라이선스 비용**(매출 규모에 따라) 발생 가능
  - (c) **스프라이트 시트(프레임 기반)** — 아무 2D 애니메이터나 가능, 단순하지만 용량↑·부드러움↓·벡터 룩앳 리그 불가
- 결정 전 위 표(입력 계약)를 견적서에 첨부하면 견적 정확도가 크게 올라갑니다.
